# CS50P (Introduction to Programming with Python) Solutions

Harvard CS50 Python 課程練習、Lab 與 Problem Set 彙整。

## 涵蓋單元 (Topics)
* `0_functions_variables`：函式、變數、型別轉換
* `1_conditionals`：條件判斷 (`if/elif/else`)
* `2_loops`：迴圈 (`for`, `while`)
* `3_exceptions`：例外處理 (`try/except`)
* `4_libraries`：外部模組 (`random`, `sys`, `requests`)
* `5_unit_tests`：單元測試 (`pytest`)
* `6_file_io`：檔案讀寫 (`csv`, `PIL`, custom formats)
* `7_regular_expressions`：正規表示式 (`re`)
* `8_object_oriented_programming`：物件導向 (`class`, `__init__`, `property`)
